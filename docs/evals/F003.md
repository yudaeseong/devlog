## 참고 (FAIL 사유는 아님)
- 이메일 정규식이 느슨해 `<script>@x.dev` 가 유효로 처리되어 가입된다. React 가 이스케이프하므로 XSS 는 아님.
- 문구 충돌 예고: F003 은 "이미 가입된 이메일이에요", feature_list 의 F004 는 "이미 사용 중인 이메일이에요" 를 요구한다. F004 구현 시 문구 변경과 F003 테스트 해시(수정 금지) 충돌이 생기므로 F004 명세에서 결정 필요(F003 테스트는 "이미 가입된 이메일이에요" 를 단정함).
- 리포터의 "step id not found: fixture@NN" 은 browser.newContext 사용 테스트에서 재현되나 결과는 통과이며 기능 결함 아님.
