# 기술 결정 기록

새 라이브러리를 추가하거나 구조를 바꾸면 한 줄로 남긴다. 최신 결정이 아래에 온다.

| 날짜 | 결정 | 이유 | 대안 |
| --- | --- | --- | --- |
| 2026-09-30 | DB는 libSQL + 직접 쓴 SQL, ORM 없음 | 설치 스크립트가 필요 없는 의존성만 쓰기 위해 (Windows에서 npm이 설치 스크립트를 막음). SQL이 그대로 보여 리뷰가 쉽다 | Prisma(엔진 설치 필요), Drizzle(도구 의존성 증가) |
| 2026-09-30 | E2E 테스트는 프로덕션 빌드로 실행 | `next dev` 는 폴더당 하나만 뜨고, 빌드 오류도 완료 전에 잡기 위해 | 개발 서버 재사용 |
| 2026-09-30 | 한 세션에 기능 하나 | 컨텍스트가 길어질수록 품질이 떨어지고, 중간에 끊겨도 기록으로 이어받기 위해 | 여러 기능 연속 구현 |
