- 새 파일 `e2e/F001-layout.spec.ts`: 위 테스트.

## 주의할 점
- 이 단계에서는 로그인 상태를 보지 않는다. 항상 '글쓰기'·'로그인'을 보여준다. 로그인 시 닉네임/로그아웃 전환은 F003·F005 담당이며, 그때 SiteHeader 가 `getCurrentUser()` 를 호출하도록 수정한다. 지금은 그 확장을 미리 구현하지 않는다.
- '/write', '/login' 페이지는 아직 없어 404 가 되어도 정상이다. 링크 존재와 `href` 만 검증한다.
- 문구는 글자 그대로: `Devlog`, `글쓰기`, `로그인`, `© Devlog` (© 는 U+00A9).
- 시맨틱 태그(`header`, `footer`, `nav`)를 써야 role 로 찾을 수 있다. 내부 이동은 `<Link>`.
- 다크 모드용 `dark:` 클래스를 함께 쓴다(예: 테두리 `border-neutral-200 dark:border-neutral-800`). 좁은 화면에서 깨지지 않게 `flex-wrap` 정도만 고려하고, 본격 반응형은 F036.
- 루트 레이아웃은 정적이어도 무방하다(DB 조회 없음). `LayoutProps<"/">` 타입은 기존 그대로 사용.
- 새 라이브러리 없음. Next.js 문서 확인이 필요하면 `node_modules/next/dist/docs/` 의 layout 관련 문서를 본다.

## 범위 밖
- 로그인 상태별 헤더 표시(닉네임, 로그아웃), 모바일 메뉴, 404 페이지 내용(F002), 다크 모드 토글, /write·/login 페이지 구현.
